# 文書作成ツール

議事録・報告書・連絡事項・メモなどを、ブラウザで編集してWord形式（.docx）で保存できるツールです。

## 主な機能

- 自由なタイトルと任意の日付追加（日本時間）
- 3階層の箇条書き、太字、赤字
- 文書プレビュー
- Wordファイルの保存と読込
- このブラウザへの下書き自動保存

## 使い方

公開ページ、またはダウンロードした `index.html` をブラウザで開いてください。サーバーへの文書アップロード処理はありません。下書きは利用中のブラウザのlocalStorageに保存されます。ブラウザのデータ削除などで消えるため、大切な文書はWord形式で保存してください。

Word読込は、このツールで出力したファイルの再編集を想定した簡易機能です。表・画像・複雑なレイアウトの再現には対応していません。

## GitHub Pagesの設定

リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/ (root)** にして保存します。

## 同梱ライブラリ
