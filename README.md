# 文書作成ツール

議事録・報告書・連絡事項・メモなどを、ブラウザで編集してWord形式（.docx）で保存できるツールです。

## 主な機能

- 自由なタイトルと任意の日付追加（日本時間）
- 3階層の箇条書き、太字、赤字
- 行単位のページ区切り（Word保存・読込と下書きに保持）
- 文書プレビュー
- Wordファイルの保存と読込
- このブラウザへの下書き自動保存

## 使い方

公開ページ、またはダウンロードした `index.html` をブラウザで開いてください。サーバーへの文書アップロード処理はありません。下書きは利用中のブラウザのlocalStorageに保存されます。ブラウザのデータ削除などで消えるため、大切な文書はWord形式で保存してください。

Word読込は、このツールで出力したファイルの再編集を想定した簡易機能です。表・画像・複雑なレイアウトの再現には対応していません。

## GitHub Pagesの設定

リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、Branchを **main**、フォルダを **/ (root)** にして保存します。

## 同梱ライブラリ

JSZip v3.10.1（MIT または GPLv3）と、その依存ライブラリをHTMLに同梱しています。配布元のライセンス表記はHTML内に保持しています。

## ページ区切り

次のページから始めたい行を選び、上下のツールバーにある「改ページ」を押してください。再度押すと解除できます。行頭でBackspaceを押しても、その行のページ区切りを解除できます。編集欄とプレビューには区切り線を表示します。自動的なページ数の計算は行いません。

テキストでは「改ページ」だけの行がコマンドになります。入力後にEnterを押すと、その行が次ページの本文行に変わります（日本語の変換確定では実行しません）。複数行の貼り付けでも利用でき、「、形式でコピー」にも区切りを含めて出力します。文中の「改ページ」は通常の文字として残ります。

```text
、ああああああああああああ
、、いいいいいい
改ページ
ううううううううううう
、ええええええええ
```

この例では「ううう…」の行から次のページが始まります。

## 水平線

「水平線」ボタンで現在の行の後ろ（空行ならその行）に横線を挿入できます。「水平線」または `---` だけの行を入力してEnterを押す、または貼り付けても作成できます。文中の語は通常の文字のままです。線の行の先頭でBackspaceを押すと解除できます。下書き・Word保存と読込・「、形式でコピー」でも保持します。コピー時には「水平線」と出力します。
